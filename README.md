# mapa-de-habilidades
Esse mapa de habilidades faz parte de um projeto da DIO que é CAIXA - Inteligência artificial na prática

ETAPA 1 – INVENTÁRIO DE HABILIDADES
1.	Sei preencher a ficha do Google Meu Negócio e fazer a manutenção da mesma;
2.	Sei usar o Canva para fazer posts, cartão de visitas, placas QR Code;
3.	Sei usar o Canva para vetorizar imagens;
4.	Otimizo a ficha do Google Meu Negócio para aparecer na primeira página de pesquisa no Google.
   
ETAPA 2 – CRUZAMENTO COM NECESSIDADES DO MERCADO
1.	Com certeza alguém pagaria por isso, porque existe uma necessidade no mercado para que pequenas empresas apareçam para o possível cliente nas pesquisas do Google, e essas habilidades resolvem um problema comum que é está visível para potenciais clientes que usam o Google antes de efetuarem uma compra ou solicitarem um serviço de fato e existe uma grande demanda para isso, já que todos os dias surgem novos pequenos negócios no mercado.
